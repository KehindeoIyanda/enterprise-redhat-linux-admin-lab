# Enterprise Red Hat-Based Linux Administration Lab

## Project Overview

This project demonstrates practical Linux system administration
using Rocky Linux 9 and other Linux systems.

The objective is to simulate enterprise infrastructure
administration tasks through hands-on laboratory exercises.

## Project Objectives

- Infrastructure provisioning
- Linux identity and access management
- Storage administration
- Configuration management and automation
- Security hardening
- Centralized logging
- Infrastructure monitoring
- System troubleshooting
- Backup and disaster recovery
- Vulnerability assessment and remediation

## Technology Stack

| Technology | Purpose |
|---|---|
| Rocky Linux 9 | Primary Linux platform |
| Ansible | Infrastructure automation |
| Bash | Shell scripting |
| Git | Version control |
| GitHub | Project documentation |
| XFS | Linux filesystem |
| LVM | Storage management |
| SSH | Secure remote administration |
| Prometheus | Infrastructure monitoring |
| Grafana | Monitoring dashboards |

## Laboratory Environment

The project uses existing physical hardware
and Linux systems to build a resource-efficient
enterprise-style administration environment.

## Project Structure

Each numbered directory represents a major
Linux administration discipline.

## Documentation Standards

Each completed lab includes:

- Objective
- Business purpose
- Prerequisites
- Implementation steps
- Commands and explanations
- Validation
- Troubleshooting
- Security considerations
- Lessons learned
